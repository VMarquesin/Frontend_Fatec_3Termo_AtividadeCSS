# Atividade Desenvolvimento HTML e CSS - Front-End

Este repositório contém o código da estilização dos exercícios da disciplina de Desenvolvimento HTML.

## Projetos

* **Exercício 01 - Layout da Pizzaria:** Evolução do wireframe para uma página web, com estrutura HTML e com estilização completa em CSS.

* **Exercício 02 - Conecta Pompeia:** Evolução do código estrutural do marketplace de serviços locais para um layout, utilizando CSS.

---

## Como visualizar os projetos no seu computador

Como os projetos foram desenvolvidos utilizando apenas HTML e CSS nativos, **não é necessário instalar nenhum programa, servidor ou ambiente de desenvolvimento (IDE)** para visualizar. 

Para rodar os sites, siga este passo a passo simples:

1. **Abra a pasta:** Navegue até a pasta onde os arquivos deste repositório estão salvos. Você verá arquivos terminados em `.html` e `.css`. **Atenção:** Mantenha os arquivos `.html` e `.css` juntos na mesma pasta para que o visual funcione corretamente.

2. **Abra no Navegador:** * Dê um **duplo clique** sobre o arquivo `.html` que deseja visualizar. Ele deve abrir automaticamente no seu navegador padrão.
   * **Alternativa:** Caso o duplo clique não funcione, clique com o **botão direito do mouse** sobre o arquivo `.html`, desça até a opção **"Abrir com"** e selecione o navegador de sua preferência.

3. **Live Server (Opcional):** * Se preferir abrir o repositório dentro do VS Code, é possível utilizar a extensão chamada **Live Server**, onde o projeto roda e atualiza automaticamente. **As instruções de uso podem ser encontradas na descrição da extensão quando for instalada**.
